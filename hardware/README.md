# Hardware

Everything physical. All models are generated by scripts, so dimensions live in code, not in hand-edited meshes.

## Folders

| Folder | What |
|---|---|
| [`v3/`](v3/) | **The current box (v3.7)**, the one all the electronics are built into: 20 printed parts, templates for the metal front, renders, the generators and the full print and assembly guide |
| [`front-sheet/`](front-sheet/) | `make_layout_v5.py` draws the front at true scale (1 unit = 1 mm): a dimensioned SVG, a reference PNG and a detail of the fold. The SVG also carries the engraving, which the v3 brass reads |
| [`parts/`](parts/) | dimensioned drawings of bought parts, from datasheets and community measurements, and our own caliper measurements where makers publish nothing ([LilyGO display](parts/lilygo-t5-s3-touch-measured.md)) |
| [`archive/2026-09-in-wall-box/`](archive/2026-09-in-wall-box/) | the first design from September 2026: a box flush in the facade insulation, a carrier plate, the v5 front sheet and the first diffuser. Superseded by v3, kept for the record |

## How the design got here

- **September:** a box flush in 14 cm of facade insulation, behind a folded 2 mm brass sheet (front v5). Printed as a
  test, it showed how much the parts and cables really need.
- **v2 (12–13 October):** the first box with all real parts, surface-mounted on the solid wooden door frame beside the
  door.
- **v3 (14–17 October, v3.0 to v3.7):** the box the electronics now run in. Each v3.x step fixed one finding on the
  printed part; see [`v3/README.md`](v3/README.md#what-changed-from-v2-and-in-v3x).
- **v4 (next):** the final box, without glued parts, and then the metal front from a metal shop.

The CAD comments are in German, as the project was designed in German.

## The engraving is a placeholder

The public front carries **MAX · ERIKA · ANNA · PAUL / MUSTERMANN**. To engrave your own names:

1. Edit `NAMES` and `FAMILY` at the top of `front-sheet/make_layout_v5.py`. Longer surnames are set
   smaller rather than squeezed.
2. Run it (needs Python with Pillow and fontTools; it uses the Segoe UI font that ships with
   Windows, which is **not** included here):
   ```
   python front-sheet/make_layout_v5.py
   ```
3. Rebuild the v3 parts with FreeCAD's command-line interpreter (see [`v3/README.md`](v3/README.md#rebuild)):
   ```
   cd v3/cad
   freecadcmd tools/v3_alles.py
   ```
   The results land in `v3/cad/out/`.

## Measure before you commit

Several parts have dimensions nobody publishes (mounting holes of the display board, module heights, the pin header
positions). The drawings in `parts/` mark them, and the v3 parameter file says for every number whether it was
measured, taken from a datasheet or chosen freely.
